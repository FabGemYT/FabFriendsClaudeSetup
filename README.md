# A Claude Code setup that does the work for you

You describe what you want. Claude builds it, tests it, puts it online as a preview, and hands
you one button: **merge**. This is the setup a non-technical founder runs every day to build and
operate real products: websites, apps, games, payments, emails, store listings. It is shared
here so friends can have the same thing.

**What you get**
- Claude does the whole job, not just the code: GitHub, Vercel, Supabase, emails, domains, store
  uploads, search setup. No homework, no "go to this dashboard and click".
- Safety guards that cannot be talked around: Claude can never push straight to your live site,
  merge on its own, deploy to production without your merge, or leak a password or key.
- A standing goal for everything your customers see: found on Google and in AI answers, offers
  built on Alex Hormozi's playbook, words a 12-year-old reads easily, nothing that sounds like AI.
- 78 skills (SEO, design, copywriting, ads, video, mobile, payments) and two reviewers.
- It updates itself from the original setup whenever you ask.

## Set it up (about an hour, mostly waiting)

You do three things. Claude does everything else.

1. **Get Claude Code** on a paid Claude plan (Pro or higher; the free plan does not include
   Claude Code). The desktop app is easiest: [claude.com/download](https://claude.com/download).
2. **Open Claude Code and paste this message:**

   ```text
   Set up my computer with my friend's Claude setup. I'm not technical, so do everything
   yourself and only ask me when a click is truly mine (a login, an "Allow", creating an
   account). Clone https://github.com/FabGemYT/FabFriendsClaudeSetup into a folder named
   claude-setup in my home folder, then read its SETUP.md and follow it step by step.
   ```

3. **Do the few clicks it asks for:** signing in to GitHub, Vercel and Supabase (with "Sign up
   with GitHub" it is one click each), adding the Claude extension to Chrome, and restarting
   Claude Code once or twice when it says so.

That's it. When it is done, try: *"Make me a website for my bakery."*

## Every day

- **Ask for what you want, in plain words.** Claude plans it, shows you the plan, builds it,
  and sends a preview link.
- **Check the preview on your phone. If it's right, merge.** Merging is the button that puts it
  live, and it is always yours.
- **"Update my setup"** pulls the latest version of this setup. Your own files are never touched.
- **"Is everything working?"** runs a full health check (about four minutes).

## What stays yours

- **Merging** (it puts things live), **the final App Store or Play Store submit**, and
  **spending money**.
- **Things Anthropic keeps human** for everyone: typing passwords, ID or card numbers, creating
  accounts, and solving CAPTCHAs. Claude signs in with Google wherever a site allows it, so
  password logins are rare.

## Private by design

Nothing personal of the person who shares this setup is in it, and nothing of yours ever comes
back here: your notes, keys and accounts live only on your computer. Every update is built
automatically, scanned for personal details and secrets, and tested before it is published.
